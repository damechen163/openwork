## Material changes from the construction prompt

1. Goose’s official repository is now `aaif-goose/goose`; the earlier `block/goose`
   path redirects after transfer to the Agentic AI Foundation.
2. LibreChat’s official repository remains under `danny-avila`, not the unavailable
   `LibreChat-AI/LibreChat` code path. Its compose file still prevents a defensible
   version-plus-digest release pin, so Issue #4 is blocked rather than silently using `latest`.
3. MinerU is not plain Apache-2.0: its additional terms trigger a formal license gate.
4. New API is AGPL-3.0 and remains external/optional.
5. Claude Code is not open-source redistributable code.

## Revalidation rule

Every dependency update must re-check the exact tag/commit, license at that ref, image
digest, release notes, and compatibility suite before changing `tested` to `true`.
