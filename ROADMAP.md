# Roadmap

- `v0.1-alpha`: repository governance, installer bootstrap, pinned compose, identity,
  runtime, sandbox, approvals, knowledge, initial packs, backup, and rollback.
- `v0.1`: repeatable installation and all release gates in the project prompt.
- `v0.2`: optional enterprise messaging approvals and upstream integration profiles.
- `v1.0`: stable public contracts and a documented compatibility/support policy.

The live work breakdown is tracked in GitHub Issues #1–#30. Scope changes require an
issue and, when architectural, an ADR.
