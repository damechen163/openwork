# Security policy

## Supported versions

No production release exists yet. Security fixes currently target the default branch
and the newest alpha release only.

## Reporting

Do not open a public issue for a suspected vulnerability or include secrets, customer
data, prompts, documents, credentials, or exploit details in public logs. Use GitHub
Private Vulnerability Reporting when enabled. Until then, contact the repository owner
through the private address listed on their GitHub profile and request a secure channel.

Include affected versions, impact, minimal reproduction, and suggested mitigation.
We will acknowledge receipt, triage severity, coordinate a fix and disclosure, and credit
reporters who wish to be credited.

Security claims require evidence. The project does not claim “100% secure” or production
readiness before the release gates are reproducibly passed.
