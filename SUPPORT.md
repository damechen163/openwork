# Support

Use GitHub Issues for reproducible bugs, feature proposals, documentation gaps, and
upstream compatibility problems. Use Discussions when enabled for usage questions.

Before filing a bug, run `openwork doctor --json`, remove all secrets and customer data,
and attach only the relevant redacted output. Never attach uploaded documents, database
contents, complete business prompts, cookies, authorization headers, or API keys.

The alpha project provides community best-effort support and no SLA. Commercial support
may be offered independently without changing the rights of Community users.
